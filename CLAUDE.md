# API Fiscal (phpfiscal)

## Telas novas
Toda página ou tela nova segue o padrão do Portal do Contador (`api-fiscal/resources/portal`):
use a skill `padrao-painel-contador` (`.claude/skills/padrao-painel-contador/SKILL.md`).
Menu lateral abre as janelas; listagem com filtros em cima; ações (novo/alterar/copiar) abrem em janela própria.
